# ML Case Studies

Five machine-learning case studies prepared for the CA assessment.

1. Hospital Readmission Prediction — Logistic Regression + L2 + ROC-AUC + threshold/cost analysis
2. Credit Card Fraud Detection — XGBoost + SMOTE + threshold tuning + feature importance
3. Product Review Sentiment — BERT fine-tuning vs LSTM baseline
4. E-Commerce Segmentation — K-Means + DBSCAN + PCA + t-SNE + RFM personas
5. Bias/Fairness — AIF360 metrics + reweighing + equalized-odds post-processing + SHAP

Cases 1 and 2 use the supplied CSV files through Google Colab upload cells. Cases 3–5 download their public datasets/packages when the notebooks are run.
