# ML Case Studies

Five machine-learning case studies prepared for the CA assessment.

1. [Case 1 - Hospital Readmission](Case_Study_1/case1_hospital_readmission.py) — Logistic Regression + L2 + ROC-AUC + threshold/cost analysis
2. [Case 2 - Credit Card Fraud](Case_Study_2/case2_credit_fraud.py) — XGBoost + SMOTE + threshold tuning + feature importance
3. [Case 3 - Product Review Sentiment](Case_Study_3/case3_sentiment_bert_lstm.py) — BERT fine-tuning vs LSTM baseline
4. [Case 4 - E-Commerce Segmentation](Case_Study_4/case4_rfm_segmentation.py) — K-Means + DBSCAN + PCA + t-SNE + RFM personas
5. [Case 5 - Fairness](Case_Study_5/case5_fairness_aif360.py) — AIF360 metrics + reweighing + equalized-odds post-processing + SHAP

Cases 1 and 2 use the supplied CSV files through Google Colab upload cells. Cases 3–5 download their public datasets/packages when the code is run.

The supplied patient and transaction CSV files are not committed to this public repository.
